# 04 — 10-Dimensional Content Complexity Model

## Explicit Complexity Dimensions

Rather than relying on ad-hoc grade branches, `ComplexityPolicy` governs 10 independent axes of complexity:

1. **Abstraction Level**: Physical everyday phenomenon → Mathematical model → Generalized tensor.
2. **Conceptual Depth**: Qualitative intuition → Single equation → Multi-variable equilibrium system.
3. **Vocabulary Complexity**: Everyday terms ("gaya putar") → Standard terms ("momen gaya") → Formal terminology ("rotational torque tensor").
4. **Mathematical Formalism**: Arithmetic ($\tau = F \times d$) → Trigonometric ($\tau = rF\sin\theta$) → Vector calculus ($\vec{\tau} = \vec{r} \times \vec{F}$).
5. **Reasoning Complexity**: Direct recall → Stepwise execution → Counterargument refutation.
6. **Example Complexity**: 1D horizontal door pivot → 2D inclined ladder with friction.
7. **Evidence Requirement**: Visual plausibility → Controlled empirical data tables.
8. **Task Open-Endedness**: Single calculation → Open-ended engineering optimization.
9. **Prerequisite Dependency**: Self-contained → Heavy multi-concept prerequisites.
10. **Misconception Depth**: Simple false premise → Subtle epistemic confounding factor.

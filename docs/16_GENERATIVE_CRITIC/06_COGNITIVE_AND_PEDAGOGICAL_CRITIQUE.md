# COGNITIVE LOAD & PEDAGOGICAL CRITIQUE
## BATCH 16 — GENERATIVE CRITIC & EXPLAINABLE MATERIAL CRITIQUE

### 1. Pedagogical Sequencing Invariants
- **Instructional Precedence**: Concepts must be introduced and formalized before students are asked to solve worked examples or perform independent practice.
- **Scaffolding Rationale**: Premature problem solving induces high anxiety and error rates, forcing rote symbol manipulation rather than deep conceptual schema construction.

### 2. Cognitive Load Theory Invariants
- **Concurrent Element Limit**: High school working memory can typically manage 3–4 novel interactive elements simultaneously. Introducing 6+ unfamiliar concepts concurrently leads to cognitive overload.
- **Split-Attention Effect**: Placing dense equations, multiple unrelated callouts, and explanatory prose on a single presentation slide induces extraneous cognitive load through constant context switching.

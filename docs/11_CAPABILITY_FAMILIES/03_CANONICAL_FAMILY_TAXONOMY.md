# 03 — Canonical Family Taxonomy

## 8 Canonical Capability Families

The KIR AI Architecture formalizes 8 canonical capability families covering 100% of pedagogical, scientific, and mathematical visual grammars:

### 1. PROCESS (`CapabilityFamily.PROCESS_VISUALIZATION`)
- **Semantic Goal**: Represents ordered transformations, procedures, or chronological stages.
- **Topologies**: Linear (`LINEAR`), Vertical (`VERTICAL`), Horizontal (`HORIZONTAL`), Branching (`BRANCHING`), Cyclic (`CYCLIC`), Pipeline (`PIPELINE`).
- **Examples**: Scientific Method, Experiment Workflow, Research Protocol, Problem Solving Steps, Reaction Mechanism, Learning Roadmap.

### 2. COMPARISON (`CapabilityFamily.COMPARATIVE_REASONING`)
- **Semantic Goal**: Represents contrasting entities, trade-offs, before-and-after states, or matrix evaluations.
- **Topologies**: Matrix (`MATRIX`), Binary Contrast (`BINARY`), Multi-Axis (`MATRIX`).
- **Examples**: Qualitative vs Quantitative, Theory Comparison, Literature Gap Matrix, Misconception Correction Card, Trade-Off Matrix.

### 3. RELATIONSHIP (`CapabilityFamily.RELATIONSHIP_MAPPING`)
- **Semantic Goal**: Represents interconnected entities, dependencies, causal links, and network topologies.
- **Topologies**: Network (`NETWORK`), Directed (`LINEAR`), Causal (`NETWORK`).
- **Examples**: Variable Causal Maps, Ecosystem Interaction Networks, System Dependency Diagrams.

### 4. HIERARCHY (`CapabilityFamily.CONCEPT_STRUCTURE`)
- **Semantic Goal**: Represents conceptual levels, taxonomic classifications, and parent-child structures.
- **Topologies**: Tree (`TREE`), Layered (`LAYERED`), Pyramid (`LAYERED`).
- **Examples**: Biological Taxonomy, Concept Hierarchy Tree, Research Problem Formulation Funnel, Bloom's Taxonomy.

### 5. REASONING (`CapabilityFamily.EVIDENCE_ANALYSIS`)
- **Semantic Goal**: Represents structured logical inference chains (Claim → Evidence → Warrant → Conclusion).
- **Topologies**: Chain (`LINEAR`), Branching (`BRANCHING`), Convergent (`LINEAR`).
- **Examples**: Evidence Reasoning Chain, Hypothesis Falsification Matrix, Toulmin Argumentation Model.

### 6. QUANTITATIVE (`CapabilityFamily.STEPWISE_REASONING` / `QUANTITATIVE_ANALYSIS`)
- **Semantic Goal**: Represents mathematical relationships, algebraic derivations, and variable mappings.
- **Topologies**: Derivation Chain (`LINEAR`), Variable Mapping (`MATRIX`).
- **Examples**: Equation Derivation Sequence, Physical Variable Reference Table, Formula Breakdown.

### 7. COLLECTION (`CapabilityFamily.CONCEPT_STRUCTURE`)
- **Semantic Goal**: Represents grouped entities, definition cards, and key takeaway grids.
- **Topologies**: Grid (`MATRIX`), List (`VERTICAL`), Cards (`MATRIX`).
- **Examples**: Core Definitions Grid, Key Takeaways Panel, Experimental Variable Inventory.

### 8. PROGRESSION (`CapabilityFamily.STEPWISE_REASONING` / `ASSESSMENT_CHECKPOINT`)
- **Semantic Goal**: Represents staged learning progression, difficulty ladders, and formative assessments.
- **Topologies**: Ladder (`LADDER`), Continuum (`LINEAR`), Milestone (`PIPELINE`).
- **Examples**: Bloom's Question Progression Ladder, Mastery Milestones, Formative Concept Checkpoints.

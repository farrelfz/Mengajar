# PERSONALIZATION TRACE & EXPLAINABILITY
## BATCH 18 — LEARNING PERSONALIZATION & ADAPTIVE PEDAGOGICAL PROFILE SYSTEM

### 1. Explainability Trace (`PersonalizationTrace`)
Every adaptation choice records its rationale:
- `decision`: Explicit action taken (e.g. `complexity reduced`, `inserted worked example`).
- `dimension`: Affected pedagogical axis (`sequence`, `complexity`, `density`, `scaffolding`).
- `rationale`: Pedagogical justification.
- `confidence`: Reliability score ($0.0 - 1.0$).

# 09 — Format-Aware Direction & Density Budgeting

## Semantic Density Budgeting (Not Pixel Coordinates)

| Target Format | Density Budget | Max Concepts per Stage | Preferred Structures |
|---|---|---|---|
| **Presentation 16:9** | `LOW` / `MINIMAL` | 1–2 | Hero statements, single concepts, process cards |
| **A4 Portrait** | `MEDIUM` / `FOCUSED` | 2–3 | Sequential reading, derivation steps, worked examples |
| **A4 Landscape** | `MEDIUM` / `ANALYTICAL` | 3–4 | 3-column matrices, comparison tables, dual pathways |

# 03 — Learning Journey Model

## Canonical Progression of Stages

A `LearningJourney` is a sequence of discrete `LearningStage` objects representing milestones in knowledge construction:

```
HOOK
  ↓
ACTIVATE_PRIOR_KNOWLEDGE
  ↓
SURFACE_INTUITION
  ↓
MISCONCEPTION / CONCEPTUAL_CONFLICT
  ↓
CONCRETE_EXPERIENCE
  ↓
CONCEPT_FORMALIZATION
  ↓
REPRESENTATION / MATHEMATICAL_DERIVATION
  ↓
WORKED_EXAMPLE
  ↓
GUIDED_PRACTICE
  ↓
INDEPENDENT_PRACTICE
  ↓
CHALLENGE
  ↓
REFLECTION / SUMMARY
```

---

## Dynamic Adaptation by Format and Density

- **16:9 Presentation**: Journey is dynamically condensed to 3–5 high-impact stages (e.g. `HOOK -> PHENOMENON -> CORE_CONCEPT -> WORKED_EXAMPLE -> SUMMARY`).
- **A4 Portrait Handout / Worksheet**: Expanded to include formal derivations, scaffolded exercises, and self-assessment checklists.

# 04 — Capability Families

## Canonical Capability Families

Capability families group functionally interchangeable rendering capabilities sharing similar pedagogical and structural patterns:

1. **`TITLE_FRAMING`**: Opening statements, presentation titles, chapter hooks, hero callouts (`presentation.hero_statement`).
2. **`CONCEPT_STRUCTURE`**: Core concept definition panels, entity introductions, hierarchical taxonomic breakdowns (`presentation.concept_introduction`, `universal.concept_hierarchy`).
3. **`PROCESS_VISUALIZATION`**: Stepwise linear pipelines, temporal workflows, research reasoning progressions, funnel reductions (`diagram.process_flow`, `research.scientific.reasoning_pathway`, `research.problem.funnel`, `research.experiment_workflow`).
4. **`COMPARATIVE_REASONING`**: Side-by-side trade-offs, misconception corrections, literature gap matrices, multi-criterion evaluations (`pedagogy.misconception_correction`, `universal.comparison_matrix`, `research.problem.gap_matrix`).
5. **`STEPWISE_REASONING`**: Mathematical equation derivations, pedagogical worked examples, progressive guided questions (`pedagogy.worked_example`, `mathematics.equation_derivation`, `pedagogy.question_progression`).
6. **`QUANTITATIVE_ANALYSIS`**: Variable tables, methodology matrices, quantitative data parameterizations (`mathematics.variable_mapping`, `research.methodology.design_matrix`).
7. **`SPATIAL_SYSTEMS`**: Geometric force vector diagrams, coordinate systems, rotational mechanics, physical simulations (`physics.mechanics.torque_diagram`, `physics.mechanics.free_body_diagram`).
8. **`EVIDENCE_ANALYSIS`**: Hypothesis testing matrices, empirical evidence chains, data validation cards (`research.scientific.hypothesis_test`, `universal.evidence_chain`).
9. **`ASSESSMENT_CHECKPOINT`**: Formative concept checkpoints, diagnostic multiple-choice assessments, reflection prompts (`pedagogy.concept_checkpoint`).
10. **`RELATIONSHIP_MAPPING`**: Variable causal diagrams, system dependency maps, factor relationship networks (`research.variable_relationship_map`).

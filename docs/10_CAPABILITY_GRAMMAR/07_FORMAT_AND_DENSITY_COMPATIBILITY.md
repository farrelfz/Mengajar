# 07 — Format & Density Compatibility Matrix

## Density Profiles

1. **`MINIMAL`** (Word count budget: 10 - 40 words):
   - Best for slide hero titles, big takeaway quotes, high-impact cards.
   - Primary formats: `presentation_16_9`, `a4_landscape`.

2. **`FOCUSED`** (Word count budget: 40 - 120 words):
   - Best for concept panels, standard slide steps, diagram cards.
   - Primary formats: `presentation_16_9`, `a4_portrait`, `a4_landscape`.

3. **`ANALYTICAL`** (Word count budget: 100 - 250 words):
   - Best for worked examples, comparison matrices, reasoning pathways.
   - Primary formats: `a4_portrait`, `a4_landscape`, `presentation_16_9`.

4. **`DENSE_REFERENCE`** (Word count budget: 200 - 500 words):
   - Best for methodology design matrices, variable mapping tables, comprehensive worksheets.
   - Primary formats: `a4_portrait`, `a4_landscape`.

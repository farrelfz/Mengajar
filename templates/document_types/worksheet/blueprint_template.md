## 2. NON-NEGOTIABLE ANTI-SPOILING CONTRACT
Every inquiry activity MUST adhere to the following invariants:
- **WITHHOLD_EXPLANATION**: TRUE (Explanations must NEVER precede student investigation)
- **WITHHOLD_FINAL_ANSWER**: TRUE (Correct predictions or values must not be visible)
- **WITHHOLD_INTERPRETATION**: TRUE (Students must deduce meaning from their own data)
- **ANSWER_LEAK_RISK**: FALSE (Zero leak of discovery targets in prompts, tables, or hints)
- **CSS_HIDING_FORBIDDEN**: TRUE (Answers cannot exist in HTML/DOM hidden by CSS; must be omitted entirely)
